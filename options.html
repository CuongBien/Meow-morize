Quick Notion Guide (3 Steps)

1
Create Connection:

Access your Notion Settings -> Connections, or visit notion.so/my-integrations. Create a new connection of type Access token named Meow-morize and copy its token secret.

2
Setup Database Columns:

Create a Database in your Notion workspace with these exact column names and formats:

  • Column Từ vựng - Type: Title (The default first column)
  • Column Dịch nghĩa - Type: Rich text
  • Column Ngữ cảnh - Type: Rich text
  • Column Nguồn - Type: URL
3
Grant Access & Copy ID:

Open the database page in Notion -> Click the ... menu on the top-right -> Connect to -> Search and add `Meow-morize` connection.

Copy the 32-character Database ID from the URL: notion.so/[DATABASE_ID]?v=... and paste it on the left.
